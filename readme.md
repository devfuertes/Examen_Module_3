# Examen Módulo 3

## ¿Qué voy a hacer en este examen?

En este examen voy a demostrar mis conocimientos sobre el uso de Git, el control de versiones, la organización del código y la implementación de tests automatizados tanto en el backend como en el frontend.

Primero, prepararé el entorno de trabajo eliminando completamente el repositorio original y creando uno nuevo desde cero. Haré un commit inicial con los archivos de configuración, protegeré la rama principal y crearé una nueva rama de desarrollo para trabajar. También configuraré una GitHub Action para que se ejecuten los tests automáticamente con cada cambio.

Después, escribiré tests automatizados para el backend utilizando **Vitest**, asegurándome de cubrir todos los métodos del controller proporcionado. Organizaré correctamente los tests y validaré que cada uno funcione correctamente.

Finalmente, escribiré tests para el frontend usando **Vitest** junto con **Testing Library**, comprobando el funcionamiento de los componentes del proyecto. También cuidaré la organización de los tests y la calidad del código.

Una vez que todo esté listo y los tests pasen correctamente, haré el merge de la rama de desarrollo a la rama principal. El objetivo es asegurarme de que todo el código esté correctamente versionado, testeado y preparado para producción.
